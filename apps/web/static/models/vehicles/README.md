# Vehicle preview assets

The bundled `.glb` files are local low-poly fallback models generated for this
project. They are not exact representations of any real vehicle make or model.

Regenerate them from the repo root with:

```bash
node apps/web/scripts/generate-vehicle-models.mjs
```

Use additional `.glb` assets here only when their license allows institutional
use and their size is appropriate for scanner/caseta devices.
